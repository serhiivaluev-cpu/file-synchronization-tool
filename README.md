# File Synchronization Tool

Консольна програма для синхронізації файлів між двома каталогами, розроблена мовою Rust.

## Основні можливості

- Рекурсивне сканування каталогів.
- Копіювання відсутніх файлів.
- Виявлення конфліктів між файлами.
- Вирішення конфліктів на користь першого каталогу.
- Автоматичне створення резервних копій.
- Журналювання операцій у файлі `sync.log`.

## Вимоги

- Встановлені Rust і Cargo.
- Операційна система Windows (перевірено).

## Встановлення

```bash
git clone https://github.com/serhiivaluev-cpu/file-synchronization-tool.git
cd file-synchronization-tool
cargo build --release
```

## Запуск

Звичайна синхронізація:

```bash
cargo run -- folder1 folder2
```

Вирішення конфліктів на користь першого каталогу:

```bash
cargo run -- folder1 folder2 --resolve-from-first
```

Замість `folder1` і `folder2` можна вказати шляхи до власних каталогів.

## Тестування

```bash
cargo test
```

## Обмеження

Програма не синхронізує видалення файлів і не виконує автоматичне вирішення конфліктів без відповідного параметра командного рядка.
